## Executor notes (apply to every task)

- **Docker only.** Run every npm/npx command as `docker compose exec app <cmd>` (CLAUDE.md). If `app` is not running, `docker compose up -d` first.
- **Tailwind does not scan `composables/`** (content globs: components, layouts, pages, plugins, app.vue). The helpers return levels, labels and numbers; every class string lives literally in RiskScorePanel.vue.
