## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 10px | 900 (black) | 1.2 |
| Body | 14px | 400 (regular) | 1.6 |
| Heading | 20px | 900 (black) | 1.2 |
| Display | 48px | 900 (black) | 1.1 |

Weight declaration: exactly 2 weights for new elements in this phase — **400 (regular)** for body/detail copy, **900 (black)** for labels, headings, the risk-score display number, and all badges/pills. This matches the codebase's dominant pattern (`font-black` is used for nearly every emphasized element; unstyled paragraph text defaults to 400).

Exception (pre-existing, not to be extended): the "Ver más/menos detalles" toggle link in `RiskCard.vue` uses `font-bold` (700). Leave it as-is; do not introduce 700-weight anywhere new in this phase.

Usage mapping for this phase's new elements:
- **Label (10px/900/1.2, uppercase, `tracking-widest`)** — sidebar category names, certainty badge text, "Cobertura" caption, breakdown-bar category names. Matches the existing `text-[10px] font-black uppercase tracking-widest` convention used throughout the Métricas panel and `RiskCard.vue`.
- **Body (14px/400/1.6)** — any new detail/paragraph text (none new beyond what's already inside `RiskCard`'s expandable section, which is unchanged).
- **Heading (20px/900/1.2)** — sidebar panel title ("Secciones" or similar), unchanged `RiskCard` category title (`text-xl font-black`).
- **Display (48px/900/1.1)** — the `puntaje_riesgo` big number (e.g. "7") in the combined risk panel header, left-aligned next to the risk label per D-08.

## Layout & Interaction Notes (phase-specific, supplements CONTEXT.md)

These resolve the three "Claude's Discretion" items from `12-CONTEXT.md`:

1. **Bar-sizing formula:** `count / max(desglose_riesgo values) × 100%` (relative-to-max, not relative-to-total) — reads as a proper comparative bar chart; relative-to-total would compress all bars toward similar-looking small percentages when there are many categories. 6% minimum width floor for visibility.
2. **Severity-pill wrap behavior on narrow viewports (<640px):** the three severity pills (Críticos/Alertas/Seguros) wrap to a second line via `flex-wrap`; the score + risk-label block on the left stays on its own line and does not stack with the pills. This keeps the score legible as the dominant element rather than shrinking the whole header.
3. **Certainty badge visual treatment:** resolved above in the Color section's "Certainty badge color mapping" table — filled pill for Alta, neutral filled for Media, outline-only for Baja, following `AnalysisStatusBadge.vue`'s pill conventions minus the status dot.

Sidebar scroll interaction (D-02): clicking a sidebar category label scrolls the findings grid to that category's **first** matching finding (`summary.hallazgos.find(h => h.categoria_riesgo === category)`), using `scrollIntoView({ behavior: 'smooth', block: 'start' })` to match the existing `animate-fade-in`/`animate-slide-up` motion language already used on the page.
