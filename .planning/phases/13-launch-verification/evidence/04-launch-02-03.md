### Edge-probe dispositions

- **Boundary** (resolved): the verified threshold is first call (no stored object, `cached=false`) vs. second call (object exists, `cached=true`). The 24-hour signed-URL expiry boundary is **not exercised** in this phase — flagged assumption, not verified.
- **Precision** (dismissed): the cache decision is a boolean `exists()` check with no numeric computation — no rounding/overflow path exists.
- **Concurrency** (flagged assumption): two concurrent first-time exports could both attempt to generate; the upload path uses `upsert: true` on the same object path, making the result idempotent (last write wins) regardless of race outcome. Only the sequential round-trip above was verified in production — concurrent-export behavior is inferred from reading the upload call's `upsert` option, not independently tested here.
- **Unclassified — "renders correctly"** (resolved): operationalized as the pdfinfo + page-1 legibility check in Task 1, which passed.
